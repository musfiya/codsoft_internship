# Tic-Tac-Toe AI

A Python-based Tic-Tac-Toe game where a human player competes against an AI powered by the Minimax algorithm.

## Features

- Human vs AI gameplay
- Minimax-based decision making
- Optimal AI strategy
- Win detection
- Draw detection
- Input validation
- Replay functionality
- Modular Python architecture

## Technologies

- Python
- Minimax Algorithm
- Recursion
- Game State Search
- Backtracking
